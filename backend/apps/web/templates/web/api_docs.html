Dokumentasi API

Semua endpoint publik bersifat baca-saja dan terbuka tanpa kunci API. Unggah survei memerlukan sesi login (atau autentikasi sesi DRF).

GET /api/surveys/

Daftar survei yang sudah selesai dan publik. Berpaginasi (20 per halaman).

GET /api/surveys/<id>/evidence.csv

Unduhan CSV seluruh baris buki (evidence), siap dibuka di spreadsheet.

POST /api/surveys/

Unggah PDF + metadata (multipart/form-data, login wajib). Diproses secara sinkron. Sukses → 201 (atau 200 bila berkas identik sudah pernah diunggah). Gagal → 400 dengan stage, reason, attempts. 

curl -X POST /api/surveys/ \
  -H "X-CSRFToken: <token>" \
  -F "file=@laporan.pdf" \
  -F "title=Survei Contoh" \
  -F "publisher=Lembaga X" \
  -F "publication_date=2026-03-01"

Skema respons

schema_version saat ini 1.0. Perubahan tidak kompatibel ke depan akan menaikkan angka versi. Field yang tidak diketahui boleh diabaikan klien.
